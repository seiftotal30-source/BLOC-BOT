# Pictures

Viewport pictures of the Bloc-Bot designs, taken in Fusion (1600 x 1100 px, shaded with edges).
One folder per design.

| Folder | Design | Views |
|---|---|---|
| `hbloc/` | H bloc, the horizontal vise (version 3, with the 0.2 mm thread clearance) | iso front-right, iso front-left, front, right, top |
| `vbloc/` | VBloc, the vertical vise (version 2) | iso front-right, iso front-left, front, right, top |
| `waffle_plate/` | waffle plate, the robot's base plate | iso front-right, iso front-left, top, bottom, iso underside |

The vise pictures show the parts as assembled in the design: base, sliding jaw, lead screw
and, beside it, the M4 thumb screw. For the print layout of the same parts see
`CAD/out/print_settings_ender5.md`.

The waffle plate is only 10 mm thick, so its front and side views show just a thin edge;
the bottom and underside views replace them. Sketches, the origin and construction planes
were hidden for these pictures.
